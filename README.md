# 233 SQN Cadet Absence Notification

**Prototype only — not operational.** The public demonstration page has submissions disabled and does not transmit cadet information.

## Publish on GitHub Pages

Open Settings > Pages > Build and deployment > Deploy from a branch > main / (root) > Save.

## Before accepting real submissions

Obtain Squadron/AAFC authorisation for external hosting and processing of minors' information. GitHub Pages cannot send email itself. A separate approved server-side submission service is needed, with secrets stored server-side, spam protection, rate limiting, retention/privacy arrangements, and verified delivery to both intended inboxes. Test using fictional data. Never commit API keys or real cadet information.

Intended recipient inboxes: admino.233sqn@airforcecadets.gov.au and co.233sqn@airforcecadets.gov.au.
